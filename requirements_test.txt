# Home Assistant version itself.
#
# Pick the newest release that pins a STABLE Home Assistant, not simply the
# newest release: the plugin publishes daily and follows Home Assistant's beta
# releases too, so "latest" regularly means testing against a beta. Check what
# a candidate pins before bumping - naming today's beta series here would go
# stale within weeks, the rule does not.
#
# 0.13.355 pins Home Assistant 2026.8.1, verified as the current stable.
pytest-homeassistant-custom-component==0.13.355

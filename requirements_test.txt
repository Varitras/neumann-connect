# Test dependencies. The plugin pins pytest, pytest-asyncio and the matching
# Home Assistant version itself.
#
# Pick the newest release that pins a STABLE Home Assistant, not simply the
# newest release: the plugin publishes daily and follows Home Assistant's beta
# releases too, so "latest" regularly means testing against a beta. Check what
# a candidate pins before bumping - naming today's beta series here would go
# stale within weeks, the rule does not.
#
# 0.13.357 pins Home Assistant 2026.8.3, verified as the current stable
# on PyPI 2026-09-01.
pytest-homeassistant-custom-component==0.13.357
# Declared rather than inherited. It arrives through the plugin above
# today, and pytest.ini relies on it (`timeout = 30`) - so the day that
# transitive dependency changes, pytest only warns "Unknown config
# option: timeout" and the safety net is silently gone.
pytest-timeout
# Pinned to the same version the lint job installs. Unpinned here, the local
# environment could lint against a different release than CI does - which is
# how a Ruff upgrade turned the build red once already.
ruff==0.16.5
